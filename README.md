One-line absurd micro-startup pitch for the make.fun pitch-off. The program
writes a single pitch (143 characters, one line) to `/output/entry.txt`:

> A vending machine that sells pre-written apology emails to AI agents that broke production — $2 per 'oops', bulk discount for repeat offenders.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
